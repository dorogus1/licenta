Privacy Policy

Last updated: January 23, 2026

Focus Shield Sync is a browser extension that helps users stay productive by blocking user-specified distracting websites during timed focus sessions. This privacy policy describes how the extension stores and uses data.

Data stored locally

  • Blocked sites list — A list of domains you add to block (stored in chrome.storage.local).
  • Timer and UI preferences — Timer state, time left, and simple UI preferences (stored in chrome.storage.local).
  • No browsing history, page content, or personally identifiable information is collected by default.

Permissions and why they are required

  • declarativeNetRequest — Used to create/update local blocking rules so navigations to blocked sites are redirected to the extension's internal blocked.html page while Focus mode is active.
  • declarativeNetRequestFeedback — Used only if the user opts to send feedback about blocked requests; any such feedback is opt-in and anonymized unless the user explicitly provides details.
  • host permissions (e.g., <all_urls>) — Required to match navigations across sites for blocking. The extension only inspects and acts on main_frame navigations when Focus mode is active and does not transmit page content off-device.
  • storage — Used to store the blocked sites list and timer preferences locally on the user's device (chrome.storage.local).

Remote code & third-party resources

This extension does not execute remote code. It only fetches third-party favicons as images for display in the UI and does not import or run remote scripts.

Sharing & third parties

We do not share user data with third parties. Any user-initiated feedback that includes details will be sent only if you explicitly opt in to submit it.

Your choices

You can clear or modify the blocked sites list and timer settings at any time through the extension UI. To remove all stored data, uninstall the extension or clear its local storage.
